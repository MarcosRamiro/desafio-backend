# Desafio Backend - API Star Wars 🚀

## Sobre o Projeto
Este é um desafio técnico que implementa uma API REST de personagens de Star Wars. O projeto serve como base para você demonstrar suas habilidades de desenvolvimento e análise de código.

## 🎯 Objetivo do Desafio
Seu objetivo é:
1. Analisar a qualidade do código existente
2. Identificar pontos de melhoria
3. Implementar as melhorias propostas

## 🔍 Pontos para Análise
Ao avaliar o código, considere:

- ✨ **Experiência do Usuário**: A API é intuitiva e fácil de usar?
- 🔧 **Qualidade do Código**: O projeto segue boas práticas de desenvolvimento?
- 🛡️ **Confiabilidade**: Como podemos tornar a aplicação mais robusta?

## ⚡ Funcionalidades da API

### Personagens
- Listar todos os personagens
- Buscar personagens por nome

### Favoritos
- Adicionar personagem aos favoritos
- Remover personagem dos favoritos
- Listar personagens favoritos

## 🛠️ Tecnologias Utilizadas

- Java 17
- Spring Boot 3.4.4
- JUnit 5
- Maven

## 🚀 Como Executar

### Pré-requisitos
- JDK 17 ou superior
- Maven 3.9+

### Comandos

1. **Construir o projeto**
```bash
mvn clean install
```

2. **Executar a aplicação**
```bash
mvn spring-boot:run
```

3. **Rodar os testes**
```bash
mvn test
```

## 💡 Dicas
- Use as collections fornecidas para testar a API:
  - `collections.json` para Insomnia/Postman
  - `client.rest` para [REST Client](https://github.com/Huachao/vscode-restclient) no VSCode
- Existem pontos de melhoria intencionais no código - encontrá-los faz parte do desafio!

## 📝 Critérios de Avaliação
- Qualidade e clareza do código
- Identificação de problemas e pontos de melhoria
- Implementação das melhorias propostas
- Justificativa das decisões técnicas
